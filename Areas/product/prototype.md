# Prototype — the demo web app

What exists for Sunday, what it is not, how to run it.

## What it is

A web app opened by QR — no install, no account — that runs the **live opener** with the
judges' phones:

- `/host` — the projector screen: QR + short URL, joined counter, the question, live bars,
  reveal with reasons, mini leaderboard, one-line class summary. Keyboard: **Space** next
  step, **R** reset (with confirm), **S** switch to simulation mode. `?sim=1` starts in
  simulation (fake players, no network needed).
- `/j/BITOLA` — the phone screen: auto nickname → Join → vote → one-line reason → result +
  points → rank.
- `/print` — A4 page with the QR and short URL.

Content is **pre-generated** and labelled as generated by TeacherAid for a named topic —
the demo does not call an AI live (decided: zero network risk on stage). The questions live
in `content/opener.json`; the working name is one variable there.

Design: playful on the phone, calm on the host screen — the same split the real product
will have.

## What it is not

- Not the product. No focus lock (needs native), no AI call, no teacher planning, no
  dashboard beyond the summary line. Say so if asked: "this is the opener; the rest is
  built the same way."
- Not Macedonian: the demo is in English so the judges read it at the pace of the script.

## Stack (so it can be reused, not thrown away)

Next.js (App Router, TypeScript) + Tailwind, deployed on Vercel; session state in Upstash
Redis; the host polls state once a second, phones every 1.5 s. Polling, not websockets, on
purpose — nothing to reconnect on stage.

## How to reset / rehearse

- Press **R** on `/host` (confirm dialog) or open `/host?reset=1`. Everyone has to
  re-scan; phones drop back to the Join screen on their own.
- `/host?motion=0` turns off entrance animations if the projector stutters.
- **S** flips to simulation in place (fake students join and vote); the header shows
  "simulation" so it stays honest. Press S again to go back to the live session.
- Rehearse the whole flow once from a real phone on mobile data before Sunday.

## After the weekend

Keep the repo; the session engine (join, vote, reveal, points) is the seed of the real
live-session service. The host/phone split becomes teacher/student.
