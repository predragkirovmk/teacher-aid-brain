# Competitors and alternatives

The judges will ask "why not X". The team already knows the names; this page gives the
one-line answer for each and the honest view of where TeacherAid is weaker.

## The map

| | Plans the lesson with AI | Students play on phones | Attendance | Focus / attention | Talks to the buyer (report) | MK curriculum + language |
|---|---|---|---|---|---|---|
| **TeacherAid** | yes | yes | yes | yes | yes | yes |
| Curipod | yes | yes | no | no | no | no (English-first, some languages) |
| Kahoot / Quizizz (Wayground) / Blooket | partly (AI quiz gen) | yes | no | no | no | no |
| Mentimeter / Wooclap | no | yes (polls) | no | no | no | no |
| MagicSchool / Brisk / Eduaide / SchoolAI | yes | no | no | no | no | no |
| ChatGPT / Claude directly | yes (unstructured) | no | no | no | no | if you prompt it |
| Google Classroom / MS Teams | no | no (distribution) | partly | no | admin stats | n/a |
| EDUINO | no | no | no | no | no | yes (content) |

## One line each

- **Curipod** (Norway) — the closest: AI-generated interactive lessons, students join by
  code, polls, drawings, word clouds. Strong product, freemium with a paid teacher tier
  (verify current price). It is a **teacher tool sold to teachers**, English-first, no
  attendance, no focus lock, no headmaster report, nothing tied to the БРО programs. If
  Curipod localized to Macedonian tomorrow it would still be a slide tool, not a lesson
  system with a buyer-side product.
- **Kahoot** — the game everyone knows. Great for a 10-minute quiz; nothing before or after
  it. Priced per teacher; schools rarely pay.
- **Quizizz (now Wayground)**, **Blooket**, **Gimkit** — Kahoot variants with different
  game modes.
- **Mentimeter / Wooclap** — polls and word clouds for lectures; the opener could be built
  with them, nothing else could.
- **MagicSchool, Brisk, Eduaide, SchoolAI** — AI assistants for teachers: plans, rubrics,
  emails. No student side. Big in the US; not in Macedonian.
- **ChatGPT + anything** — what the champion teacher does today: plan in ChatGPT, quiz in
  Kahoot, attendance on paper. Five tabs. The answer to "why not free tools" is "**one tool
  for the whole lesson, not five**" — and none of the five speak to the headmaster.
- **Google Classroom / Teams** — the school's file cabinet and remote-lesson channel. The
  45 minutes in the room are not their problem.
- **EDUINO** — national content platform (МОН + UNICEF). A library, not a live tool. Partner.
- **Focus apps** (Opal, Forest, one sec) — prove the focus-lock mechanism exists on personal
  phones; none are classroom products.

## Where TeacherAid is weaker (know it before a judge says it)

- Curipod and Kahoot have years of polish, templates, and a community. TeacherAid has a
  weekend.
- Any of them could add attendance in a sprint. The defensible parts are the **buyer-side
  product** (the report), the **MK curriculum corpus**, the **school relationships and
  habit**, and the **school-vs-school leaderboard** — not any single feature.
- Free tools are free. The counter is that the school pays, not the teacher, and it pays for
  the report and the whole-lesson flow, not for a quiz.

## The moat, honestly (decided answer)

1. **School relationships and teacher habit** — daily use is hard to displace.
2. **Leaderboard network effect** — every school added makes the game bigger for the rest.
3. Building: the corpus of MK lessons edited by real teachers.
